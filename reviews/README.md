## 本轮采用的内容标准

一个概念除了定义，还应说明它要解决什么问题、由什么交易或估计形成、怎样进入报表，以及何时不能使用常见简式。重要计算展示中间步骤，独立教学情景与真实历史材料分开标注。

重要案例需要连通输入、计算、报表影响、解释和后续验证。对可能有多个原因的现象，给出能够区分解释的证据；对关键估计，解释假设改变如何影响结果。新增练习检验计算与判断，不仅增加名词识别题。

原始资料带读应有具体定位和示范。模拟附注明确标为自编，真实摘录注明期间与来源；未取得的信息保留为缺口，不能为了让表格完整而填零或编造。

离线程序检查目录、内部链接、导航、折叠答案和指定数值勾稽，基础练习允许增加。北辰基准数据与原有真实公司摘录保持单独记录，扩写情景不混入原始基准。

审阅记录与程序共同提供可复查的修改证据；程序不对全部会计判断给出保证，也不自动核查外部网站可用性。具体规则和真实数值的来源放在对应章节。阅读入口见[全书目录](../textbook/README.md)。
