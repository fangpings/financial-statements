# 读懂美国上市公司财报 从商业交易到经营判断

这本教材面向没有会计基础的读者。只要求百分比、四则运算和简单代数，目标是独立寻找并阅读美国上市公司的原始披露，从报表与附注解释经营、现金、义务和估计，再完成有证据的分析。

教材编写与本轮扩写日期为 2026-10-04，共八篇、36 章、6 份附录。正文从交易与会计处理进入逐步算例，再连接原始披露、分析判断和带推理的练习；第 04、10、15、22、26、30、34 章有分篇综合作业，第 36 章是第八篇综合毕业项目。行业第 34 章分保险、REITs、资源企业三个单元，可分次阅读。

## 阅读方法

按章顺读基础与分析篇，再选行业专题，最后完成 35—36。第一遍理解业务如何进入账户，第二遍亲手复算，第三遍脱离参考答案阅读真实报告。附注需要随主表一起读；把来源、计算和自己的推断分开记录。

较长章节可分两次完成：先跟完一组完整交易与报表变化，再读变化情景、原始附注和进阶实作。暂时不要展开答案，先尝试说清每个加减项的原因。只会套出结果、不能解释为何加回或扣除，说明还需要回到交易过程。

第 35 章示范怎样把一家公司的利润、现金、权益和关键附注接起来；第 36 章要求你独立完成同样的工作。[附录 D](appendix-d-templates.md)同时提供空白模板与已填好的分析示例。逐篇审阅和补写记录见[修订记录](../reviews/README.md)。

核心假设企业北辰设备贯穿第 05—10 章与第 36 章，单位为千美元，Y0—Y3 为教学年度。其他章节标明独立情景，不应额外叠加到北辰年度报表。真实案例固定历史财年，不能当作当前公司情况；资料版本与访问限制见附录 C。

本书以采用 US GAAP 的美国国内上市公司为主，外国发行人与 IFRS 见附录 E。估值和宏观传导衔接相邻教材，不用股价变化代替对财报解释的验证。

## 阶段验收

- 01—04：找到正确主体与文件，区分报告期和发布时间，处理单季、累计、财年与版本。
- 05—10：把一组交易编成简化报表，并独立完成现金与权益勾稽。
- 11—22：能沿附注解释收入、投入、债务和估计，区分现金支付、损益确认与表内余额。
- 23—30：能把比率接回商业过程，提出竞争性解释，核查管理层调整和叙述。
- 31—36：按行业改变方法，完成真实年度阅读、季度更新和一份可复核报告。
