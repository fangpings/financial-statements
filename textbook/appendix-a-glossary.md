# 附录 A 中英财报术语与阅读提醒

[目录](README.md) · [公式](appendix-b-formulas.md)

英文名称因公司而异，本表用于识别，不代表同名项目一定同口径。遇到陌生字段，先看表头和附注，再查翻译。

## 报告与期间

| 英文 | 中文 | 阅读提醒 |
| --- | --- | --- |
| Annual report / Form 10-K | 年度报告 | 公司年报展示版与正式申报范围未必完全相同 |
| Form 10-Q | 季度报告 | 同时检查单季和年初累计 |
| Form 8-K | 当期重大事项等报告 | 业绩新闻稿可能作为附件 |
| Proxy statement / DEF 14A | 代理投票文件 | 常含治理、高管薪酬与激励 |
| MD&A | 管理层讨论与分析 | 区分事实、解释和预测 |
| Fiscal year / FY | 财年 | 未必自然年 |
| Year to date / YTD | 年初至今累计 | 不能直接当单季 |
| Trailing twelve months / TTM | 过去十二个月 | 历史滚动窗口，不是预测 |
| Restatement | 重述 | 保存更正前后版本及范围 |
| Unaudited | 未经审计 | 不能称为年度审计意见 |

## 报表与盈利

| 英文 | 中文 | 阅读提醒 |
| --- | --- | --- |
| Balance sheet / Statement of financial position | 资产负债表 | 时点余额 |
| Income statement / Statement of operations / Earnings statement | 利润表 | 名称不同，核对列报范围 |
| Statement of cash flows | 现金流量表 | 含非现金调节不等于每行都是现金 |
| Statement of stockholders’ equity | 股东权益变动表 | 利润与股东交易分开 |
| Revenue / Net sales | 收入／净销售 | 退货、折扣、总额净额需查政策 |
| Cost of revenue / Cost of sales / COGS | 收入成本／销售成本 | 不同公司包含项目不同 |
| Gross profit / Gross margin | 毛利／毛利率 | Gross margin 在有些表里指毛利金额 |
| Operating income | 营业利润 | 不自动等于所有定义的 EBIT |
| SG&A | 销售一般及管理费用 | 可能合并列报多个功能 |
| R&D | 研发 | 注意资本化及收购技术的不同处理 |
| Net income attributable to parent | 归属于母公司股东的净利润 | 与集团总利润可能不同 |
| Basic / Diluted EPS | 基本／稀释每股收益 | 使用对应利润与期间加权股数 |
| Discontinued operations | 终止经营 | 比较期范围需统一 |
| OCI / AOCI | 其他综合收益／累计其他综合收益 | 前者流量，后者权益余额 |

## 经营资产与负债

| 英文 | 中文 | 阅读提醒 |
| --- | --- | --- |
| Cash equivalents | 现金等价物 | 不等于全部短期投资 |
| Restricted cash | 受限现金 | 不一定可自由偿债或分配 |
| Accounts receivable / Trade receivables | 应收账款 | 查总额、损失准备和净额 |
| Allowance for credit losses | 信用损失准备 | 估计余额，不是专用现金 |
| Contract asset | 合同资产 | 收款权利还依赖非时间条件 |
| Contract liability / Deferred revenue / Unearned revenue | 合同负债／递延收入／未实现收入 | 需查具体范围与履约时间 |
| Inventory | 存货 | 可能分原料、在产品、产成品 |
| Write-down / Write-off | 减记／核销 | 不可一律理解为当期新损失 |
| Prepaid expense | 预付费用资产 | 付款早于资源消耗 |
| Accounts payable | 应付账款 | 查是否含特殊融资安排 |
| Accrued expense | 应计费用负债 | 已发生未支付 |
| Working capital | 营运资金 | 会计流动口径与经营分析口径不同 |
| PP&E | 不动产厂房设备 | 看原值、累计折旧及净额 |
| Depreciation / Amortization / Depletion | 折旧／摊销／折耗 | 加回现金流不代表没有成本 |
| Capex | 资本开支 | 现金与非现金取得要区分 |

## 融资投资与估计

| 英文 | 中文 | 阅读提醒 |
| --- | --- | --- |
| Principal / Carrying amount / Fair value | 本金／账面金额／公允价值 | 债务到期按合同处理 |
| Current portion of long-term debt | 长期债务流动部分 | 不能遗漏近期到期金额 |
| Covenant | 债务契约 | 用合同定义测试 |
| Revolving credit facility | 循环授信 | 授权、可用、已提取三者不同 |
| Right-of-use asset / ROU | 使用权资产 | 并非都在开始时现金购买 |
| Lease liability | 租赁负债 | 现值不同于未折现到期付款 |
| SBC / Stock-based compensation | 股权薪酬 | 成本、现金与稀释各有路径 |
| Treasury stock | 库存股 | 权益项目，不是投资资产 |
| Goodwill | 商誉 | 企业合并对价分配后的剩余 |
| Impairment | 减值 | 不同资产测试不同 |
| Noncontrolling interest / NCI | 非控股权益 | 注意利润与现金归属 |
| Equity method | 权益法 | 投资收益与分红收现不同 |
| Deferred tax asset / liability | 递延税资产／负债 | 不等于现金税 |
| Valuation allowance | 估值备抵 | 常用于递延税资产可实现性 |
| Commitment / Contingency | 承诺／或有事项 | 注意已入账与额外风险的重叠 |
| Material weakness | 内部控制重大缺陷 | 不是所有金额已被证实错误 |
| Critical audit matter / CAM | 关键审计事项 | 不等于保留意见 |

## 行业指标

ARR、RPO、同店销售、抽成率、NOI、FFO、AFFO、NIM、CET1 与综合成本率均须带定义。尤其公司自定义 KPI，第一次出现时记录分子、分母、期间、纳入范围和变化，不能只保留缩写。行业章节提供具体例子。

## 读懂一行英文科目，而不是逐字翻译

遇到一行陌生文字，依次判断它在回答什么问题：这是某日余额，还是某段时间的变化？列的是总额、抵减项还是净额？数字归属于整个集团还是母公司股东？它是报表事实、管理层自定指标，还是附注中的未来安排？完成这四个判断后，中文翻译才有稳定含义。

例如，`Accounts receivable, net` 不是“净收到的款项”。它是应收余额扣相关抵减后的净额。假设应收总额 100、信用损失准备 3，净额为 97；其中没有任何信息保证已经收到 97 现金。再看现金流量表同名项目，它可能列的是用来调节经营现金流的应收变动，既不是期末余额，也不一定等于两张资产负债表的简单差。位置和表头会改变同一术语的读法。

`Additions to property and equipment` 出现在现金流量表中时，应结合表的现金口径理解；资产附注中的 additions 可能包含非现金取得。仅用同一个中文“新增固定资产”，会隐藏这一差别。资料表应保留“现金支出”还是“资产增加”的标记，不能只记录字段缩写。

## 经常被误译的限定词

| 英文限定 | 它提示你核对什么 | 容易产生的误读 |
| --- | --- | --- |
| Net | 净掉了什么，能否找到总额和抵减项目 | 以为都表示净利润或现金净流入 |
| Gross | 在扣除哪些项目之前 | 以为金额一定比所有其他口径大 |
| Attributable to | 利润或权益归属谁 | 把集团全部利润当成母公司普通股利润 |
| As of | 某个时点 | 与一整年流量直接相加 |
| For the year / Three months ended | 截止日之前的一年或三个月 | 只看截止日期而忽略期间长度 |
| Current | 流动分类或当前期间，取决于上下文 | 一律译成“本期” |
| Provision | 在税费、信用损失等语境中具体指什么 | 以为已经存入一笔备用现金 |
| Reserve / Allowance | 估计负债、抵减资产还是其他含义 | 以为“准备金”都能用于支付 |
| Recognized | 按会计规则已确认 | 以为已经收款或支付 |
| Realized | 具体交易或计量语境中的实现 | 以为一定没有任何应收或结算时差 |
| Accrued | 已计提或应计但支付时点可能不同 | 以为是未来尚未发生的预算 |
| Reclassified / Recast | 分类或比较呈现发生改变 | 一律认定是错误重述 |

“准备”尤其需要回到科目性质。信用损失准备通常抵减相关资产；诉讼计提可能形成负债；管理层谈到“现金储备”则可能指持有的流动资源。它们在中文中听起来接近，却位于资产负债表的不同位置。一个公司的信用损失准备增加 10，并不说明有一个银行账户多存了 10。

## 三段自编英文披露怎样批注

以下英文均为本书自编教学句，不是任何公司的引文或准则措辞。

**句子一：** “Revenue increased primarily due to higher volume, partially offset by unfavorable currency effects.”

先标出它是原因解释：数量增加产生正影响，汇率产生负影响。“Primarily”没有给出精确金额，“partially offset”也没有告诉你抵消多少。可以写“管理层将增长主要归因于销量，汇率部分抵消”，不能写成“全部增长均由销量贡献”，更不能据此算出有机增长率。下一步找数量、价格、汇率或分部桥是否提供量化支持。

**句子二：** “The carrying amount of debt is presented net of unamortized issuance costs.”

标出三个对象：债务账面额、未摊销发行成本、净列示。若本金 100，未摊销成本 2，忽略其他因素，账面额可能为 98；到期偿还本金并不因此变成 98。下一步对照债务附注的本金和到期表，并理解后续摊销如何进入利息费用。不要仅因表内余额低于本金，就把差额看成债权人豁免。

**句子三：** “The adjustment had no effect on cash flows.”

这句话在其上下文中说明某项调整没有改变相关现金流，并不自动证明该事项没有经济成本、没有未来支付、没有稀释，或者不影响偿债能力。资产减值、股权薪酬和非现金计量的机制各不相同。先查“adjustment”究竟指哪个项目、哪个期间，才能评价它为何没有当期现金影响。

阅读中不必每个词都翻成中文。保留原字段，再写一两句账户含义，通常比只留下一个中文简称更利于复核。真正读懂的标志，是能说明金额属于谁、覆盖多久、如何确认、怎样变化，以及它能支持和不能支持什么结论。
