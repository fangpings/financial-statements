## 学习任务与信息边界

本章将全书方法用于 Microsoft 的历史报表，再用下一季度更新。它是阅读方法练习，不评价当前股价。先独立完成每一步，再看参考计算。年度材料为 [2024 年报](https://www.microsoft.com/investor/reports/ar24/index.html)；正式 10-K 的报告期截至 2024-06-30，申报日为 2024-07-30，身份见 [SEC 申报目录](https://www.sec.gov/Archives/edgar/data/789019/000095017024087843/0000950170-24-087843-index.html)。年报网站附带的股东信日期不能用来替代 10-K 申报日。

## 1 先画阅读路线

第一轮写商业模式：选择一类产品或服务，说明客户买什么、收费按何种单位、履约发生在时点还是期间。不要试图用一句话覆盖所有业务。

第二轮定位报表与审计：检查利润、资产负债、现金流、综合收益与权益变动；记录审计意见对象及重要估计入口。第三轮追踪三个问题：收入增长来源、利润与现金差异、现金投资和并购对资源及义务的影响。每个问题都要至少连接一张主表与一份附注。

这套路线可用于任何一般工商企业，但最后进入哪份附注，应由业务与重要性决定。阅读银行时需改用第 33 章框架。

## 4 从计算进入附注

| 问题 | 阅读位置 | 应提交的结果 |
| --- | --- | --- |
| 各种收入怎样形成 | 会计政策与分部信息 | 一条合同至收入的时间线 |
| 增长中是否含新增合并范围 | 企业合并 | 收购日、对价与经营范围区别 |
| 投入了哪些资源 | 固定资产与租赁 | 现金投入与非现金取得分别列示 |
| 每股结果如何形成 | EPS 与员工奖励 | 基本至稀释分母的解释 |
| 义务何时使用现金 | 债务、租赁与或有事项 | 一张不重复的期限表 |
| 哪些数字依赖重要判断 | 审计报告与相关附注 | 估计变量、支持与后续验证 |

参考写法是“该解释由哪些字段支持，还不能量化哪些部分”，而不是把管理层原因全部换成自己的口吻。若无法把报告增长全部拆成数量、价格、汇率与收购，应明确没有足够信息，不凑一个看似精确的桥。

## 6 一段合格分析的写法

以下是依据上述有限数字写出的分析示范，不是完整公司价值结论：

> 年度收入与营业利润率均改善，基本和稀释 EPS 可以由利润与对应股数复算。经营现金流扣现金购建设备后仍为正。下一季度收入继续同比增长，CFO 同比上升，但所定义的季度 FCF 下降，需要进一步解释投资强度与未来回报。现有计算尚未分离全部并购、业务组合和会计估计影响，也没有建立未来支付时间表，因此不能据此断言增长完全来自原有业务或现金可无条件全部分配。

这个段落把可见结果、必要核查与判断限制连接起来。完成附注任务后，应将其中能够解决的缺口替换为具体发现，不能永远停留在“需要进一步研究”。

## 7 现在真正逐表走一遍：先把利润形成过程算完整

以下补充摘录仍来自本章同一份 FY2024 年报，金额均为百万美元。它们是历史原表字段；随后的分解与判断由本教材计算，不代表公司对未来的预测。先在网页定位 Income Statements，再按以下顺序复算：

```text
收入                                      245,122
减：收入成本                               74,114
毛利                                      171,008
减：研发                                   29,510
减：销售及营销                             24,456
减：一般及行政                              7,609
营业利润                                  109,433
加：其他收入（费用）净额                    −1,646
税前利润                                  107,787
减：所得税费用                             19,651
净利润                                     88,136
```

先观察分类：这里的“其他收入（费用）净额”不能直接改名为利息费用，收入成本也不能改名为现金采购。计算中使用原始行名，才能在附注中找到正确对象。研发列为费用不意味着所有与技术相关的现金支出都在这一行，固定资产、收购技术和其他开发成本仍需各看政策。

将上一年同口径毛利 146,052 与营业费用 27,195、22,759、7,575 接起来，营业费用合计从 57,529 升至 61,575，增加 4,046；毛利增加 24,956，所以营业利润增加 20,910。这个桥严格相等：24,956−4,046＝20,910。它证明毛利增加超过了营业费用增加，但还没有证明原因是提价、产品组合、规模效应还是收购。

再看净利润桥：营业利润增加 20,910；其他净损益由正 788 变为负 1,646，形成不利变化 2,434；税费增加 2,701。故净利润增加 20,910−2,434−2,701＝15,775，与 88,136−72,361 一致。只写“净利润增长由经营改善推动”方向可能合理，却遗漏了融资、投资等其他损益和税项对增量的抵消。

这一步的产物应是一个可以逐行回到原表的金额桥，而非十几个未解释的比率。完成后，再按第 23、24 章计算率、分部和资本回报，才不容易把税后结果全部归因产品竞争力。

## 8 资产负债表：增长的资源在哪里，资金来自哪里

继续定位 Balance Sheets，先做两个基础检查：

```text
FY2024：512,163 资产 = 243,686 负债 + 268,477 权益
FY2023：411,976 资产 = 205,753 负债 + 206,223 权益
总资产增加 = 100,187
负债增加37,933 + 权益增加62,254 = 100,187
```

这只能证明表内勾稽，没有解释资产质量。选择三个变化较大的项目进一步阅读：固定资产净额由 95,641 至 135,591，增加 39,950；商誉由 67,886 至 119,220，增加 51,334；净无形资产由 9,366 至 27,597，增加 18,231。它们合计增加 109,515，超过总资产增加，意味着其余资产合计净减少 9,328。读者不必马上抄全部项目，也能识别资源结构发生了显著变化。

下一步应把固定资产接到现金投入及租赁，把商誉与无形资产接到企业合并。不能把商誉增加 51,334 当作当年现金收购付款，也不能把固定资产净增加 39,950 当作现金资本开支：折旧、并购取得、融资租赁、处置和汇率等会使这些金额不同。

再查流动性口径：期末现金及等价物为 18,315，而现金、等价物及短期投资合计 75,543。两者差 57,228，来自短期投资。现金流量表期末现金应接 18,315，而不是接 75,543。短期投资可能与流动性相关，但买卖投资属于现金流桥的另一部分，不能为使“现金更多”而直接换掉定义。

这里已经得出一个比“总资产增长 24%”更有内容的观察：资源扩张主要集中于长期经营及收购相关资产，现金和投资口径需要分开。尚未得出的结论是这些投入的未来回报是否足够；这需要项目、收购和经营结果，而不是资产增加本身。

## 9 从净利润到 CFO：完整调节，而不是只加折旧

原表 CFO 为 118,548，净利润为 88,136，差额 30,412。下面逐项保留原表调节，括号或负号代表减少，避免自行把不清楚项目并入“其他”：

| FY2024 调节项 | 对 CFO 的影响 |
| --- | ---: |
| 折旧、摊销及其他 | 22,287 |
| 股权薪酬费用 | 10,734 |
| 投资及衍生工具净已确认损失 | 305 |
| 递延所得税 | −4,738 |
| 应收账款 | −7,191 |
| 存货 | 1,284 |
| 其他流动资产 | −1,648 |
| 其他长期资产 | −6,817 |
| 应付账款 | 3,545 |
| 未实现收入 | 5,348 |
| 所得税 | 1,687 |
| 其他流动负债 | 4,867 |
| 其他长期负债 | 749 |
| 调节合计 | 30,412 |

先将前四项相加，得到 28,588；其余经营资产负债调节合计 1,824；88,136＋28,588＋1,824＝118,548。这个分组只帮助分析，不把公司原行“折旧、摊销及其他”缩写成纯折旧。递延税为负也是从净利润转现金所需的调节，不等于公司当期直接支付了同额递延税现金。

现在可以检验“CFO 高于利润”的来源：按本表，主要差额来自非现金等调节，经营资产负债净贡献相对小；但净额小不等于每项都小，应收和其他长期资产的负贡献被若干负债及库存正贡献部分抵消。若只看合计 1,824，就会漏掉经营内部的方向差异。

取应收作一次交叉检查：资产负债表流动应收净额增加 56,924−48,688＝8,236，而 CFO 应收调节为 −7,191，绝对金额差 1,045。这个差额告诉你简单的期末差不是完整现金调节；不能擅自把 1,045 全部命名为收购或坏账。本章未重建该项目全部合并、外币和其他变动，正确做法是保留待解释差额，再回查附注和对应现金流计算说明。

读者可以用同一方法检查库存和未实现收入。能够识别差额、提出正确取证路径，比强行用一个未经核实原因把表凑平更重要。

## 10 投资和融资如何解释现金下降

用 Cash Flows Statements 的三个活动合计完成第一层桥：

```text
期初现金及等价物                           34,704
经营活动                                  118,548
投资活动                                  −96,970
融资活动                                  −37,757
汇率对现金及等价物的影响                      −210
期末现金及等价物                           18,315
```

总变动为 −16,389。尽管 CFO 为正且较大，投资、融资和汇率净流出更多，因此现金下降。它不与公司盈利矛盾，也不能单凭下降就解释为经营现金枯竭。

再展开投资活动：现金购建固定资产 −44,477；收购企业净现金及购买无形和其他资产合计 −69,132；买入投资 −17,732；投资到期 24,775；出售投资 10,894；其他净额 −1,298。合计恰为 −96,970。注意收购相关行的名称本来就包含多类交易，不能将整个 69,132 宣称为某一个收购的购买价。

本书简式 FCF 为 74,071，仅扣了现金固定资产支出。若再扣上述收购及其他资产购买行 69,132，余量为 4,939；这个自算小计尚未包含投资证券买卖、融资和其他项，应使用完整名称，不能另称“真正 FCF”。它的用途是显示：单看 CFO−Capex 会漏掉当年一项重要资本用途。

融资活动可再分为债务现金净流入 5,250＋24,395−29,070＝575，股票发行 2,002、回购 −17,254、现金分红 −21,771 和其他 −1,309，合计 −37,757。由此可以看见股东分配、债务交易和其他活动同时发生；不能根据年末债务余额变化倒算唯一借款现金额。

## 11 权益表与 EPS：净利润没有全部留在权益里

定位 Stockholders’ Equity Statements，先从三个子账户分别勾稽，再合计，避免把权益当成单一“累计利润”：

```text
普通股及缴入资本：
93,718 + 2,002 − 5,712 + 10,734 + 181 = 100,923

留存收益：
118,848 + 88,136 − 22,293 − 11,547 = 173,144

累计其他综合损益：
−6,343 + 753 = −5,590

权益合计：
100,923 + 173,144 − 5,590 = 268,477
```

这里回购影响普通股及缴入资本与留存收益两个子账户，不能只从其中一处读取全部回购影响。权益表分红减少额 22,293 与现金流量表实际支付 21,771 也不同；权益确认与现金支付的时点可能不同，读者应继续查分红及应付关系，而不是把差额直接认作抄错。

OCI 为 753，因此综合收益 88,136＋753＝88,889；它与净利润不同，却同样不是现金流。权益表将本期损益、OCI与股东交易分开，正是为了防止把所有权益增加都称作本期赚钱。

最后回到 EPS，稀释股数与基本股数差为 7,469−7,431＝38。这个期间加权影响不能直接称为期末新发行 38 百万股。第 18 章解释了股权奖励、回购和加权时间；本章的任务是把同一公司的利润、股数、权益交易和实际现金回购并列阅读，避免仅凭 EPS 上升推断股东权益没有稀释。

## 12 两条附注路线示范：从科目走到经济机制

第一条路线是“收入—应收/未实现收入—收入政策—审计关注”。从 Note 13 实际复算未实现收入桥：期初 53,813＋递延收入增加 148,701−未实现收入转为收入 142,330＝期末 60,184；期末也等于资产负债表流动部分 57,582＋长期部分 2,602。原报告对应定位均在本章的[年报原文 Note 13](https://www.microsoft.com/investor/reports/ar24/index.html)。

这个桥证明余额增加 6,371 是本期递延增加大于本期转收入的净结果，不能解释为当年新增销售只有 6,371，也不能把 148,701 直接称为已收现金。余额变化 6,371 与 CFO 的未实现收入调节 5,348 又差 1,023；该差额提醒两张表的变化口径不完全相同，本章不擅自将其全部归因收购、汇率或其他事项。已完成的结论是：公司存在较大规模的收入递延与履约转收入循环，时点余额、期间确认与现金调节必须分别阅读。

阅读时不能给整个集团设置一个统一的“先收钱后确认”模型。作为独立教学对照，预付一年服务 120 可能随履约逐月确认 10；另一个合同若满足时点确认条件，收入可能先于分期收款。两者都可能出现在同一集团，净应收和预收余额因而不能用一个简单合同解释。这里的 120、10 是教学数字，不是 Microsoft 披露合同。

CAM 提供的帮助是指出合同拆分、时点和估计等判断入口，不是证明收入存在错误。我们已将该入口接到具体报表及附注，因此分析比“审计无保留所以收入没问题”多了一层可以继续验证的机制。

第二条路线是“长期资产增加—投资现金支出—租赁附注—未来义务”。Note 14 的 FY2024 实际数据显示，交换租赁义务取得的融资租赁使用权资产为 11,633；融资租赁融资活动现金支付为 1,286；融资租赁经营活动现金支付为 734，均为百万美元。前者是非现金取得资源，第二项是租赁本金等融资现金支付，第三项对应利息经营现金支付；它们与主表现金资本开支 44,477 是不同的量。[年报 Note 14](https://www.microsoft.com/investor/reports/ar24/index.html)

所以，44,477 没有描述全部新增资源取得，11,633 也不能当作同年额外付出的现金。本书可另定义“扣融资租赁本金后现金余量”＝118,548−44,477−1,286＝72,785；734 已在经营现金流中，不能再扣。若把 11,633 加入某个资源投入指标，必须注明非现金与现金混合口径，并考虑以后租赁本金支付的重复计算风险；不能同时把取得资产和偿还融资都当作同一年的独立资本开支成本。

这条附注路线已得到具体结果：简式 FCF 74,071 未扣融资租赁本金，也未表现本期新增非现金租赁资源。因此它适合作为声明口径的现金小计，不能单独衡量全部资源投入或可分配现金。下一步再通过到期表研究未来租赁支付，不能用当期 1,286 当作以后每年恒定支付。企业合并则需另沿 Note 8 的购买价分配及现金交易阅读，不用净无形资产变化凑出收购成本。

这条路线已经解决“单看简式 FCF 是否覆盖全部重大资本用途”的问题：没有覆盖。本章尚未完成全部收购项目回报和设备增量产出模型，因此不能给出资本配置创造价值的最终判断。限制必须与已完成的发现并列，不能因为还有未知就把全部已知计算抹掉。

## 13 下一季应更新哪些判断，而不只是更新数字

FY2025 Q1 的 CFO 同比增加 3,597，现金设备支出增加 5,006，因此简式 FCF 同比减少 1,409。这个金额桥可以直接验证：3,597−5,006＝−1,409。它比“现金变差”更准确，因为经营现金和投资支出朝不同方向变化。

若以收入归一化，年度现金设备支出强度为 44,477/245,122≈18.14%；新季度为 14,923/65,585≈22.75%。可以记录该期现金支出相对收入更高，但季度支付集中度、租赁和项目进度会影响比例，不能立即将 22.75% 当作以后每年稳态资本强度。

建立滚动底稿时，把已解决问题、未解决问题和新问题分开。例如年度已解决现金减少的主桥；未解决投资回报；新季度看到更高现金设备投入，需要补项目建设与投产证据。若公司重列分部，应替换同一口径历史序列而保留原版本，不把新旧分部名称相似当成范围一致。

### 进阶实作：解释 CFO 与 FCF 的不同变化

仅使用第 5 节季度表，计算 CFO 增速、现金设备支出增速及 FCF 增速，说明三者为何不能用同一个“现金增长率”代替。再提出一个能支持投资有效、一个可能表明回报不足的后续可观察事实。

<details><summary>进阶实作解析</summary>

CFO 增速为 3,597/30,583≈11.76%；现金设备支出增速为 5,006/9,917≈50.48%；简式 FCF 增速为 −1,409/20,666≈−6.82%。CFO 观察经营活动现金，资本开支观察部分长期资产现金投入，FCF 是两者差额；它们回答不同问题。支持投资有效的证据可以是新增产能投用并带来持续增量现金与合理利用率；反向证据可以是长期闲置、项目取消或现金回报持续低于原计划。单季收入增长不能独立把新增现金回报归到这些新投资。
