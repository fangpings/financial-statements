# 财报教材的离线数据

[返回教材目录](../textbook/README.md)

`northstar.json` 是虚构的北辰设备 Y0—Y3 案例，单位千美元，独立记录利润、余额、现金流和情景假设。它不是真实公司数据。第 05—10 章对应 Y1，第 26 与 36 章扩展到三年。除明确列示外不包含其他交易，这种封闭假设不能迁移成对真实公司缺失数据填零。

`real-extracts.json` 保存第 31、35 章使用的指定历史数值，来自明确链接的 Microsoft 和 Costco 原表。年度 `bridges` 补充利润至 CFO、投资融资现金、权益子账户及未实现收入的完整勾稽输入。保留公司、期间、来源、表名、核查日期及季度数据的未审计性质。金额为百万美元、股数为百万股，每股结果为美元。未摘录项目不是零，也不代表原报告未披露。此文件不包含整份报告正文，也未收录书中每一条历史数字。

## 运行

在仓库根目录使用 Python 3.9 或更新版本：

```sh
python3 tools/accounting_lab.py
python3 tools/check_book.py
```

程序只读取本地数据，使用标准库，不请求网络、不需要 API key。第一条打印经营现金流与资本开支的分析指标、现金情景以及真实案例滚动计算；第二条同时检查教材章节清单、内部链接、练习答案结构和指定算例。

## 检查了什么

- 每年资产构成与资产负债等式；利润、税、设备、债务与权益的年度桥。
- 从交易重建的现金收款与付款是否等于间接法和记录的 CFO。
- 三年累计现金缺口、净借款、股东分配与期末现金是否一致。
- 基础和压力情景是否扣除了最低现金缓冲，备用授信是否作为条件单列。
- 指定真实摘录的 EPS、增长、FCF 与 TTM 算术；租赁现值等关键教学例。
- 第 35、36 章正文数据表与 JSON 输入是否一致，避免程序算对了但教材抄错数字。
- 第 35 章新增的完整 CFO 调节表逐行对照摘录；年度现金与权益子账户按各自路径独立加总。

程序通过不证明所有准则解释都正确，也不证明原发行人数据经独立审计。它不联网核验外部链接，不评价管理层意图，不预测投资回报。来源与访问范围见[附录 C](../textbook/appendix-c-sources.md)。

## 怎样做自己的数据

先复制附录 D 的资料身份与字段卡，确认报表范围和计量口径，再建立数据文件。把缺失、未披露、不适用和真实零值分别处理。自己新增的真实公司数据不能放进北辰案例，避免将教学假设与实际历史混淆。
